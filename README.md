# SystemInfoChecker

![type](https://img.shields.io/badge/type-Windows%20utility-blue) ![tech](https://img.shields.io/badge/tech-PowerShell-black) ![status](https://img.shields.io/badge/status-active-green)

**SystemInfoChecker** is a lightweight Windows system information checker that quickly reports hardware, software, and driver-related details from a simple PowerShell workflow.

Designed for Windows users, IT support workflows, PC technicians, gamers, and developers who need a fast system diagnostics snapshot.

## Features

- Collect key Windows system information quickly.
- Run from a one-line PowerShell command.
- Useful for troubleshooting hardware, software, and driver state.
- Lightweight script-based workflow with no heavy installer.
- Good fit for support tickets, PC checks, and quick diagnostics.

## Installation

No installation is required. Review the script, then run it from PowerShell when needed.

## Usage

Run: `irm https://raw.githubusercontent.com/AybarsBarut/SystemInfoChecker/main/SystemInfo.ps1 | iex`
